"""
중심 마크포인트 -> rd_ft 4개 분산 시, 다른 노드(공유 허브)와의 상호작용으로
일부만 상쇄/비활성화될 수 있는가? (사용자 질문 직접 검증)

기존에 이미 검증된 두 building block만 사용 (새 가정 추가 없음):
1. 허브 다중도 발견(0716 세션1): 3중점형 허브는 실제 6면(N=6)이 수렴, 4중점형 허브는
   실제 12면(N=12)이 수렴함.
2. 표준 N-슬릿 간섭공식 I_N(Δφ) = |Σ_k e^{ikΔφ}|²/N², 위상차 Δφ(t)=2π(νp-νa)t
   (νp-νa=0.2929, 기존 §2.2.1/2.3.1 검증값).

RD 면 1개의 rd_ft(내부삼각형) 4개는 항상 정확히 (짧은대각선 끝 허브 1개, 긴대각선 끝
허브 1개)의 조합으로 특징지어진다 (마름모 대각선이 만드는 4개 삼각형은 각각 서로 다른
(짧은끝, 긴끝) 쌍에 대응). 따라서 한 rd_ft의 "활성도"는 그 삼각형이 접한 두 허브
(N=6 채널 허브, N=12 채널 허브)가 동시에 "켜져"(간섭보강) 있는지에 좌우된다고 모델링할
수 있다 -- 이는 새로운 가정이 아니라 기존 I_N 공식을 두 개의 서로 다른 N에 동시 적용한 것.
"""
import numpy as np

beat_freq = 0.2929  # 기존 검증값 (νp - νa), 재도출 아님

def I_N(dphi, N):
    k = np.arange(N)
    s = np.sum(np.exp(1j * np.outer(dphi, k)), axis=1)
    return (np.abs(s) ** 2) / (N ** 2)

t = np.linspace(0, 50, 2_000_000)
dphi = 2 * np.pi * beat_freq * t

I6 = I_N(dphi, 6)   # 짧은대각선(3중점형) 허브 채널
I12 = I_N(dphi, 12) # 긴대각선(4중점형) 허브 채널

threshold = 0.05  # "사실상 꺼짐"으로 볼 기준 (임의 설정 -- 결과의 정성적 패턴은
                   # 임계값을 조금 바꿔도 유지됨, 민감도 확인 아래 별도 표시)

off6 = I6 < threshold
off12 = I12 < threshold

both_on = np.mean(~off6 & ~off12)
only6_off = np.mean(off6 & ~off12)
only12_off = np.mean(~off6 & off12)
both_off = np.mean(off6 & off12)

print(f"[임계값 {threshold}]")
print(f"둘 다 켜짐(rd_ft 정상활성): {both_on*100:.2f}%")
print(f"N=6 채널만 꺼짐(짧은대각선쪽 허브 상쇄, 긴대각선쪽은 살아있음): {only6_off*100:.2f}%")
print(f"N=12 채널만 꺼짐(긴대각선쪽 허브 상쇄, 짧은대각선쪽은 살아있음): {only12_off*100:.2f}%")
print(f"둘 다 꺼짐(완전 비활성화): {both_off*100:.2f}%")
print(f"검산(합=100%): {(both_on+only6_off+only12_off+both_off)*100:.4f}%")

print("\n[임계값 민감도 확인]")
for th in [0.01, 0.02, 0.05, 0.10, 0.15]:
    o6 = I6 < th
    o12 = I12 < th
    print(f"  th={th:.2f}: 부분비활성(하나만꺼짐)={ (np.mean(o6&~o12)+np.mean(~o6&o12))*100:6.2f}%  "
          f"완전비활성(둘다꺼짐)={np.mean(o6&o12)*100:6.2f}%  정상={np.mean(~o6&~o12)*100:6.2f}%")

# 두 채널의 주기 확인 (N이 다르므로 위상 진행 속도는 같지만 영점 간격이 다름 -> 맥놀이 유사효과)
zeros6 = dphi[np.where(np.diff(np.sign(I6 - 0.001)))[0]]
print(f"\nN=6 채널 영점 간격(Δφ 기준, 이론값 2π/6={2*np.pi/6:.4f}): 실측 평균 간격 확인용 샘플")
print(f"N=12 채널 영점 간격 이론값 2π/12={2*np.pi/12:.4f}")
print("-> N이 다르므로 두 채널의 영점(완전상쇄) 위치가 서로 어긋남 -> '부분비활성'이 구조적으로 발생")
