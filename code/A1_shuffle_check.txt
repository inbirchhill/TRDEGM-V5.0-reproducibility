"""A1 신호의 셔플대조군 검증 -- rho 값의 허브 배정을 무작위로 섞어도 같은 효과가 나는지"""
import numpy as np
from scipy import stats
from swing_eom import build_system

nodes, idx, n_hubs, Omega0, edges, H, cluster_idx = build_system(depth=0, buffer_radius=6)
pos0 = np.array([H.nodes[n]['pos'] for n in nodes])
r0_edges = np.linalg.norm(pos0[edges[:,0]]-pos0[edges[:,1]], axis=1)
q_param=4.0
def phi(s): return np.exp(-2*q_param*s)

def rho_of(x):
    d = x[edges[:,0]]-x[edges[:,1]]
    r = np.linalg.norm(d,axis=1)
    strain = r/r0_edges-1.0
    ph = phi(strain)
    rho = np.zeros(n_hubs)
    np.add.at(rho, edges[:,0], ph); np.add.at(rho, edges[:,1], ph)
    return rho/rho.max()

K_const=0.28
def rhs(theta,v,x_disp,beta,perm=None,gamma=1.0):
    dth=v; dthij=theta[edges[:,0]]-theta[edges[:,1]]; s=np.sin(dthij)
    coup=np.zeros(n_hubs)
    np.add.at(coup,edges[:,0],-K_const*s); np.add.at(coup,edges[:,1],K_const*s)
    rho = rho_of(x_disp)
    if perm is not None: rho = rho[perm]
    Omega_eff = Omega0*(1+beta*rho)
    return dth, gamma*Omega_eff-gamma*v+coup

def rk4(theta,v,dt,x_disp,beta,perm=None):
    k1t,k1v=rhs(theta,v,x_disp,beta,perm)
    k2t,k2v=rhs(theta+0.5*dt*k1t,v+0.5*dt*k1v,x_disp,beta,perm)
    k3t,k3v=rhs(theta+0.5*dt*k2t,v+0.5*dt*k2v,x_disp,beta,perm)
    k4t,k4v=rhs(theta+dt*k3t,v+dt*k3v,x_disp,beta,perm)
    return theta+(dt/6)*(k1t+2*k2t+2*k3t+k4t), v+(dt/6)*(k1v+2*k2v+2*k3v+k4v)

def run_one(beta,kick_amp,seed,perm=None,T=40.0,dt=0.02,grace=15.0):
    rng = np.random.default_rng(seed)
    x_disp = pos0+rng.normal(scale=kick_amp,size=pos0.shape)
    theta = rng.uniform(0,2*np.pi,n_hubs); v=np.zeros(n_hubs)
    n_steps=int(T/dt); rs=[]
    for step in range(n_steps):
        theta,v = rk4(theta,v,dt,x_disp,beta,perm)
        t=step*dt
        if t>grace: rs.append(np.abs(np.mean(np.exp(1j*theta))))
    return np.mean(rs)

n_seeds=15; seeds=list(range(n_seeds)); beta=0.2

def get_delta(perm):
    f0 = np.array([run_one(0.0,0.3,s,perm) for s in seeds])
    fB = np.array([run_one(beta,0.3,s,perm) for s in seeds])
    return (fB-f0).mean()

d_real = get_delta(None)
print(f"원본(beta={beta}) delta={d_real:+.5f}")
shufs=[]
for ss in range(15):
    perm = np.random.default_rng(2000+ss).permutation(n_hubs)
    d = get_delta(perm)
    shufs.append(d)
    print(f"  셔플#{ss}: delta={d:+.5f}")
shufs=np.array(shufs)
print(f"\n셔플 평균={shufs.mean():+.5f}, 표준편차={shufs.std():.5f}")
print(f"원본이 셔플분포에서 떨어진 정도: {(d_real-shufs.mean())/shufs.std():.2f} sigma")
